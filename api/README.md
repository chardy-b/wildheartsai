# Wild Hearts API (Cloudflare Workers)

The Hono backend replacing the Next app's API routes, on Cloudflare Workers with D1. Plan and status: [`docs/superpowers/plans/2026-10-30-cloudflare-migration.md`](../docs/superpowers/plans/2026-10-30-cloudflare-migration.md). Production still runs on Vercel until the cutover.

## Layout

- `src/app.ts`: the Hono app. Every route is under `/api`, at the path the Next app serves today.
- `src/db/schema/`: the main D1 database (binding `DB`), a 1:1 port of the Postgres schema. Table and column names must not change: sealed values are bound to them, and `test/schema-parity.test.ts` checks them against `src/lib/db/*-schema.ts`.
- `src/db/chat/schema.ts`: the chat database (binding `CHAT_DB`), bound only to the chat Worker (`src/chat/`, `wrangler.chat.jsonc`).
- `src/data/scope.ts`: **the only way to reach a person's data.** D1 has no row-level security, so `forUser(db, userId)` adds the owner condition to every query. Route code can't import tables (lint rule in the root `eslint.config.mjs`). `system(db)` is for cross-person jobs. New tables with a person's data go in `USER_TABLES`; `test/user-tables.test.ts` fails otherwise.
- `src/auth/`: Better Auth on D1 (`/api/auth/*`) and `/api/session` for the web Worker (`src/routes/auth.ts`). Email has no provider yet: see `src/auth/email.ts`.
- `src/crypto/`: the sealing code, ported from `src/lib/crypto/` with identical formats. `test/crypto.test.ts` opens values sealed by the Node code.
- `migrations/`, `chat-migrations/`: generated by `npm run db:generate`, applied with `wrangler d1 migrations apply`.

Transactions work differently on D1. Follow [`docs/superpowers/specs/2026-10-30-d1-transaction-audit.md`](../docs/superpowers/specs/2026-10-30-d1-transaction-audit.md) when porting code that used `db.transaction`, `asUser` or row locks.

## Develop

```bash
cd api
npm ci
cp .dev.vars.example .dev.vars   # then fill in local values
npm run db:migrate:local
npm run dev
```

## Checks

```bash
cd api
npm run typecheck
npm test     # Vitest inside workerd with real D1 bindings; no network or Cloudflare account needed
```

Lint runs from the repository root (`npm run lint`).
